# VALORA Data Strategy & Machine Learning Foundations

## Core Principle

> **VALORA's primary intelligence dataset is generated organically by VALORA's own operational system.**

Do **NOT** treat external Kaggle datasets or third-party web scrapers as prerequisites to shipping intelligent capabilities. VALORA's unique competitive advantage is the proprietary operational data generated by residents, HOAs, and contractors using the system daily.

## Critical Operational Signals to Capture

Every user action in the community lifecycle generates high-value data for downstream intelligence. The database must record and preserve:

1. **Temporal Duration Metrics:**
   - `logged_at` → `reviewed_at` (HOA responsiveness / review latency)
   - `reviewed_at` → `assigned_at` (Dispatch turnaround)
   - `assigned_at` → `in_progress_at` (Contractor mobilization time)
   - `in_progress_at` → `resolved_at` (Work order resolution duration)
   - `resolved_at` → `closed_at` (Resident confirmation delay)

2. **Categorical & Geospatial Density Signals:**
   - Complaint category distributions (infrastructure vs. security vs. administrative)
   - Unit-level and block-level recurring failure hotspots
   - Estate-level security incident frequencies and seasonal spikes

3. **Performance & Quality Telemetry:**
   - Service provider completion rates, cost variances (quoted vs. actual), and resident satisfaction ratings
   - Resident dispute/reopen frequency on completed work orders
   - HOA announcement frequency and communication health

4. **Time-Series Score Snapshots:**
   - Historical Living Scores and sub-score component trajectories
   - Correlated property valuation snapshots over time

## Architecture for Future ML Readiness

- **Schema Discipline:** Capture clean, typed timestamps, foreign keys, and normalized statuses.
- **Audit Trails:** Never mutate historical transition records in place. Use event log tables (`complaint_events`, `score_snapshots`).
- **External Data Adapters:** External municipal or property registry valuation feeds should enter through decoupled adapter interfaces, augmenting—not replacing—internal operational intelligence.
